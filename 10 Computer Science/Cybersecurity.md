# Cybersecurity & Reverse Engineering

> A structured outline and resource bank for systems security, binary exploitation, and reverse engineering.

---

## 🗺️ Learning Roadmap

- [ ] **CS Principles & Discrete Math**: Binary representations, boolean logic, memory models.
- [ ] **Hardware Interaction**: CPU registers, instruction pointer (`RIP`), calling conventions.
- [ ] **Low-Level Programming**: C/C++ memory allocation, pointers, buffer overflows, format strings.
- [ ] **Operating Systems Internals**: Virtual memory, paging, system calls, ELF and PE binaries.
- [ ] **Assembly & Reverse Engineering**: x86-64 disassembly, stack frames, control flow analysis.
- [ ] **Advanced Windows & Linux Internals**: Processes, threads, handles, ACLs, kernel drivers.
- [ ] **Exploitation Techniques**: ROP chains, shellcoding, heap exploitation, bypassing ASLR/DEP.
