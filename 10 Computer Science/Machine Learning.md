# Machine Learning

> *"Machine learning is basically us telling a machine to be a scientist. Acquire data, find patterns, classify/analyze, and interpret. We teach the machine to perform well as a scientist, tell them to use a specific algorithm and mathematical equation, and when they perform well, we deploy them."*

---

## 🔬 Core Learning Paradigms

$$\text{Inputs / Features } (X) \longrightarrow \left[ \text{Model Parameters } (\theta) \right] \longrightarrow \text{Outputs / Predictions } (Y)$$

### 1. Supervised Learning (Predictive Models)
- Uses labeled historical and statistical data to infer what will happen.
- Maps **independent variables** (features) to **dependent variables** (labels/targets).
- Tasks: Classification (discrete), Regression (continuous).

### 2. Unsupervised Learning (Descriptive Models)
- Uses unlabeled data to explain what happened and uncover latent patterns.
- Tasks: Clustering, Dimensionality Reduction, Anomaly Detection.

### 3. Reinforcement Learning
- **Agent $\longleftrightarrow$ Environment** interaction.
- Learns optimal policies via state, action, and reward signals.
