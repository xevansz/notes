# Game Development & Graphics Programming

> A comprehensive roadmap and curated collection of resources for learning graphics programming, shaders, game engines, and low-level rendering pipelines.

---

## 🧭 Foundational Path: C++ & Graphics Theory

1. **C++ Foundation**: [LearnCPP.com](https://www.learncpp.com/) — The gold standard for modern C++.
2. **Beginner / Intermediate Projects**: [javidx9 (OneLoneCoder)](https://www.youtube.com/channel/UC-yuWVUplUJZvieEligKBkA) — Fantastic hands-on C++ rendering and engine projects.
3. **OpenGL First**: [LearnOpenGL.com](https://learnopengl.com/) — Master OpenGL before tackling Vulkan to absorb graphics theory without Vulkan's extreme boilerplate.
4. **WebGL / Canvas Prototyping**: `p5.js`, `three.js`.

---

## 🌋 Modern Vulkan 1.3 Roadmap

> [!WARNING]
> **Avoid**: Do NOT use `vulkan-tutorial.com` (outdated patterns). Ensure all Vulkan materials focus on **Vulkan 1.3+** (dynamic rendering, synchronization2).

- [How To Vulkan](https://www.howtovulkan.com/) — Great modern introductory guide.
- [VkGuide.dev](https://vkguide.dev/) — High quality, in-depth Vulkan tutorial modernizing render passes.
- [Arseny Kapoulkine (@zeuxcg)](https://www.youtube.com/@zeuxcg) — Essential deep dives on advanced mesh shading and GPU pipelines.
- **Books**:
  - *Vulkan 3D Graphics Rendering Cookbook*
  - *Mastering Graphics with Vulkan* (Pre-1.3, but excellent techniques)

## ⚙️ Game Engine Architecture

- [Game Engine Architecture by Jason Gregory](https://www.gameenginebook.com/) — The definitive industry roadmap for building game engines.
- [Casey Muratori (@mollyrocket) — Handmade Hero](https://www.youtube.com/@mollyrocket) — 600+ episode masterclass building a game engine from absolute scratch in C without libraries.
- [Travis Vroman](https://www.youtube.com/@travisvroman) — Educational series building a 3D engine from scratch in Vulkan and C (Kohi engine).

## 🎨 Advanced Rendering & Mathematics Books

| Resource | Focus |
| :--- | :--- |
| *Foundations of Game Engine Development, Vol 1: Mathematics* | Vectors, matrices, quaternions, transformations |
| *Foundations of Game Engine Development, Vol 2: Rendering* | Complete foundational graphics techniques |
| *Real-Time Rendering (RTR)* | The industry standard reference encyclopedia |
| [Google Filament Documentation](https://google.github.io/filament/main.html) | Physically Based Rendering (PBR) and BRDF equations |
| [PBRT: Physically Based Rendering](https://www.pbrt.org/) | Offline ray tracing and global illumination |
| *GPU ZEN 03 & 04* | Cutting-edge advanced rendering techniques |
