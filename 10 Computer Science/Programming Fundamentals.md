# Programming Fundamentals & Craft

> *"Reading docs for everything is the best way to go about doing anything. Everything is a tool; we need to learn how to use it and apply the methods directly from first-party documentation."*

---

## 🧱 The Core Pillars

To solve real problems effectively, ground understanding in:
- **Data Structures & Algorithms**
- **Clean Code & SOLID Principles**
- **Object-Oriented & Functional Paradigms**
- **Design Patterns** (GoF, Structural, Behavioral)
- **Distributed Computing**

---

## 📖 Essential Reading & Wisdom

### Classics & Essays
- [Teach Yourself Programming in Ten Years (Peter Norvig)](http://norvig.com/21-days.html) — Mastery takes long-term deliberate practice, not 21-day shortcuts.
- [How To Become A Hacker (Eric S. Raymond)](http://www.catb.org/~esr/faqs/hacker-howto.html)
- [How To Ask Questions The Smart Way (ESR)](http://www.catb.org/~esr/faqs/smart-questions.html)
- [The Jargon File (ESR)](http://www.catb.org/jargon/html/index.html)
- [The Loginataka](http://catb.org/~esr/faqs/loginataka.html)
- [From The Transistor To The Web Browser (Geohot)](https://github.com/geohot/fromthetransistor)

### Book Recommendations
- *A Common-Sense Guide to Data Structures and Algorithms* — Jay Wengrow
- *The Programmer's Brain* — Dr. Felienne Hermans
- [Gentoomen Library (PDF Repository)](https://theswissbay.ch/pdf/Gentoomen%20Library/)

## 🛠️ Deliberate Practice & Projects

- **Interactive Platforms**:
  - [CodeCrafters](https://codecrafters.io/) — Recreate Git, Redis, Docker, and SQLite from scratch.
  - [CSES Problem Set (e.g. Weird Algorithm)](https://cses.fi/problemset/task/1068) — High quality algorithmic problem set.
  - [Exercism — Learn Rust](https://exercism.org/tracks/rust) — Mentored coding practice.
- **Language Deep Dives**:
  - [Write Yourself a Scheme in 48 Hours (Jonathan Tang)](https://en.wikibooks.org/wiki/Write_Yourself_a_Scheme_in_48_Hours) — Haskell interpreter tutorial.
- **Hands-On System Projects**:
  - [Building an Independent Mail Server Guide](https://www.c0ffee.net/blog/mail-server-guide)
  - [Managing Dotfiles with Git Bare Repos](https://www.anand-iyer.com/blog/2018/a-simpler-way-to-manage-your-dotfiles/)
  - [Wiby Guide](https://wiby.me/about/guide.html)
